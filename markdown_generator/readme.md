# Legacy content-generation utilities

These Python scripts, Jupyter notebooks, and TSV files were inherited from
AcademicPages and are retained for reference. They are not part of this site's
Jekyll build or GitHub Pages deployment, and the TSV rows contain sample data.

Current publication metadata is maintained directly in `_publications/*.md`.
Do not run the publication generators against the current collection: their
older output format does not include all of this site's publication fields.
The talk generators also write collection files and should not be run with the
sample TSV data.

The scripts and notebooks retain their upstream documentation and provenance.
See the [main README](../README.md) for the commands used to build this website.
