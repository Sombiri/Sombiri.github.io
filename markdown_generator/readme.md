# Jupyter notebook markdown generator

Publication metadata for this website is maintained directly in `_publications/*.md`.
The publication TSV, Python script, and notebook in this directory are legacy
AcademicPages examples, not a second source of publication records. Do not run
them against the current collection; edit the records in `_publications` instead.

These .ipynb files are Jupyter notebook files that convert a TSV containing structured data about talks (`talks.tsv`) or presentations (`presentations.tsv`) into individual markdown files that will be properly formatted for the academicpages template. The notebooks contain a lot of documentation about the process. The .py files are pure python that do the same things if they are executed in a terminal, they just don't have pretty documentation.
